---
title: "8. Existing Design Analysis"
description: "Audit the design process, visual language, components, and regional requirements."
---

Before building a design system for an existing product, understand what already exists.

The original roadmap highlights:

- current design process
- visual audit
- design elements
- common components
- experimentation requirements
- locale requirements
- documentation
