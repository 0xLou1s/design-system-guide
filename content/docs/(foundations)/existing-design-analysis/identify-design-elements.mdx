---
title: "8.3 Identify design elements"
description: "Existing Design Analysis · Section 8.3"
---

Create an inventory of foundational values:

- colors
- font families
- font sizes
- font weights
- line heights
- spacing
- borders
- radius
- shadows
- icon sizes
- breakpoints
- z-index layers
- motion durations
- easing curves

Later, these become token candidates.
