---
title: "8.4 Identify components"
description: "Existing Design Analysis · Section 8.4"
---

Inventory repeated UI.

For each component, record:

```text
Component
Variants
Sizes
States
Behaviors
Responsive behavior
Accessibility behavior
Existing implementations
Usage frequency
```

Example:

```text
Button
├── variants
│   ├── primary
│   ├── secondary
│   ├── ghost
│   └── destructive
├── sizes
│   ├── sm
│   ├── md
│   └── lg
└── states
    ├── default
    ├── hover
    ├── active
    ├── focus-visible
    ├── disabled
    └── loading
```
