---
title: Dependencies
description: The cheapest bundle is the one you did not install.
---

Most oversized bundles are not badly written application code. They are
dependencies, chosen quickly, that turned out to be far larger than expected.

## Check the cost before installing

[Bundlephobia](https://bundlephobia.com/) reports a package's minified and
compressed size, plus its dependency tree, before you commit to it. Thirty
seconds during code review.

The classic example: Moment.js is around 70kB compressed and bundles every
locale. `date-fns` or the native `Intl.DateTimeFormat` do most of what people
used it for at a fraction of the cost. Moment itself now recommends against
using it in new projects.

Questions worth asking:

- **How much of it will we use?** A 50kB library for one function is a bad
  trade, and usually that function is thirty lines.
- **Does it tree-shake?** A modular ES-module package lets you pay only for what
  you import. A monolithic CommonJS one does not.
- **What does it pull in?** A small package with five transitive dependencies is
  not small.
- **Can the platform do it?** `fetch`, `Intl`, `structuredClone`,
  `URLSearchParams` and `Object.groupBy` replaced a lot of libraries.

## Audit what you already ship

A bundle analyzer renders your build as a treemap — the fastest way to find a
dependency you forgot about, or a library included twice at different versions.

Duplicate packages are common and nearly invisible without one. Two versions of
the same library because two dependencies each pinned their own is pure waste.

## Keep them current

Updates bring optimizations and security fixes, and a large version gap makes
each upgrade harder than doing them incrementally. Automate the noise with
Dependabot or Renovate.

Do not update blindly — read the changelog for anything that ships to the
browser, and watch the bundle size after.

## Enforce a limit

[Size Limit](https://github.com/ai/size-limit) fails CI when the bundle exceeds
a threshold, so a costly dependency shows up on the PR that added it rather than
six months later.

```json title="package.json"
{
  "size-limit": [{ "path": "dist/index.js", "limit": "120 kB" }]
}
```
