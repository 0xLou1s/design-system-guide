Cursor's posting asks for someone **equally comfortable in Figma and your code editor**.

That phrasing is precise. Not "can open Figma" — comfortable. The difference is whether you can contribute inside the file or only read from it.

You do not need to become a visual designer in Figma. You need enough fluency that the file is a place you work rather than a specification you receive.

## The mental model

Figma maps onto things you already know, which makes it much faster to learn than it looks:

```text
Figma              code
─────────────────────────────────────────
frame              a div with layout
auto layout        flexbox
constraints        how children respond to resize
component          a component
variant            a prop with named values
instance           a usage of that component
variable           a design token
library            a published package
```

Auto layout **is** flexbox — same axis, same gap, same alignment, same padding. If you know flexbox you already know auto layout; you are only learning where the controls are.
